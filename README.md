# AssisTech BOT — Landing Page

Landing page oficial do AssisTech BOT, o assistente inteligente para assistências técnicas no WhatsApp.

## Stack
- **Framework:** Astro 6
- **Styling:** Tailwind CSS 4
- **Componentes:** Astro (SSR-friendly/Static)
- **Deploy:** Cloudflare Pages (Static output)

## Estrutura
- `src/components/sections/` — Seções da LP (Hero, FAQ, etc)
- `src/layouts/` — Layout base com meta tags e fontes
- `src/config.ts` — Configuração central (Links Cakto, trial)

## Comandos
- `npm run dev` — Iniciar servidor de desenvolvimento
- `npm run build` — Gerar build estático em `dist/`
- `npm run preview` — Visualizar o build localmente

## Design
Segue o `design-guide.md` da raiz do projeto:
- **Cores:** Preto (#050505) + Verde Neon (#7CFF00)
- **Tipografia:** Inter (800-900 para títulos)
- **Mascote:** AT-Core (capacete com visor neon)
